# Madame Lia — V1

Site vitrine statique, en français. Fond blanc, titres éditoriaux olive, héros de dunes inspiré de la référence Miro.

## Aperçu local

Depuis ce dossier : `python3 -m http.server 4173 --directory dist`, puis ouvrir `http://localhost:4173`.

## Contenus à compléter

- `dist/services.json` : textes, tarifs, durée, livraison et contenu des 8 prestations.
- `dist/index.html` : biographie, portrait, photo d’enfance, texte « Brava de… », e-mail, Instagram et mentions légales.
- Les emplacements de photos sont volontaires. Pour les remplacer, adapter les cartes dans `dist/app.js` ; placer les images dans `dist/assets/`.
- Le formulaire prépare une demande copiable ou téléchargeable. Aucun message n’est envoyé tant qu’une destination n’est pas configurée.

## Visuel de dunes

Fichier : `dist/assets/dunes.webp`. Généré avec l’outil intégré imagegen, puis converti en WebP pour le site.

Prompt final : photographie réaliste panoramique de dunes du Sahara à l’aube, inspirée uniquement du petit héros sable en haut à droite de la référence Miro ; sable doré et caramel, ombres naturelles, dunes dans les 35–40 % inférieurs, grand ciel ivoire/beige dans les 60–65 % supérieurs, lumière douce, esthétique éditoriale argentique discrète ; aucun texte, logo, personnage ou construction.

Polices Cormorant Garamond et Manrope hébergées localement (Google Fonts, SIL Open Font License).
